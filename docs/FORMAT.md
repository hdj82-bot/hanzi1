# 데이터 형식 규약 (数据格式规范)

이 저장소의 모든 학습 노트는 **파일 1개 = 항목 1개** 원칙을 따릅니다.
파일 맨 위에 YAML frontmatter로 구조화된 정보를 적고, 본문에 서술형 내용을 적습니다.

이 형식을 지키면 나중에 목차·검색·퀴즈·웹페이지를 **자동 생성**할 수 있습니다.
형식을 지키지 않은 파일은 자동 생성 대상에서 누락됩니다.

---

## 1. 사자성어 (`chengyu/`)

### 파일 이름

성조를 뺀 병음을 하이픈으로 연결한 ASCII 이름을 씁니다.

```
日就月将 → chengyu/ri-jiu-yue-jiang.md
画蛇添足 → chengyu/hua-she-tian-zu.md
```

한글·한자 파일명을 쓰지 않는 이유: URL이 깨지지 않고, 병음 순으로 자동 정렬되어
중국어 사전과 같은 순서가 됩니다.

### Frontmatter 필드

**필수 (없으면 색인에서 누락됨)**

| 필드 | 형식 | 예시 | 설명 |
| --- | --- | --- | --- |
| `simplified` | 문자열 | `日就月将` | 간체자 표제 |
| `pinyin` | 문자열 | `rì jiù yuè jiāng` | 성조 부호 포함, 글자마다 띄어쓰기 |
| `hangul` | 문자열 | `일취월장` | 한국 한자음 |
| `meaning_ko` | 한 줄 | `나날이 나아지고 다달이 발전함` | 색인 표에 들어갈 짧은 뜻 |
| `status` | `draft` \| `done` | `done` | 작성 완료 여부 |

**선택 (알게 되면 채우기)**

| 필드 | 형식 | 예시 | 설명 |
| --- | --- | --- | --- |
| `traditional` | 문자열 | `日就月將` | 번체자. 간체와 같으면 생략 |
| `hanja` | 문자열 | `日就月將` | 한국에서 쓰는 정자 표기 |
| `meaning_zh` | 한 줄 | `每天有成就，每月有进步` | 중국어 뜻풀이 |
| `source` | 문자열 | `诗经·周颂·敬之` | 출전. 책·편명까지 |
| `category` | 문자열 | `학습·노력` | 대분류 하나만 |
| `tags` | 배열 | `[노력, 성장]` | 자유 태그 |
| `used_in_korean` | `true` \| `false` | `true` | 한국어에서도 그대로 쓰는 성어인지 |
| `korean_equivalent` | 문자열 | `괄목상대` | 뜻이 비슷한 한국 성어·속담 |
| `hsk` | 숫자 | `6` | HSK 지정 급수 |
| `updated` | `YYYY-MM-DD` | `2026-09-15` | 마지막 수정일 |

### 본문 구조

정해진 6개 소제목을 **순서대로** 씁니다. 내용이 없으면 소제목만 남기고 비워둡니다
(나중에 "무엇이 비었는지" 자동으로 찾아낼 수 있습니다).

```markdown
## 뜻 / 释义
## 출전 / 出典
## 예문 / 例句
## 한국어 쓰임 / 韩语用法
## 어디서 봤나 / 见于
## 메모 / 笔记
```

`_TEMPLATE.md`를 복사해서 시작하세요. 완성 예시는 `ri-jiu-yue-jiang.md`입니다.

---

## 2. 공통 규칙

- **인코딩은 UTF-8**, 줄바꿈은 LF
- 날짜는 전부 `YYYY-MM-DD`
- 다른 노트를 가리킬 때는 상대 경로 링크: `[일취월장](../chengyu/ri-jiu-yue-jiang.md)`
- 한중 병기는 **한국어 먼저, 중국어 나중** 순서로 통일
- 확실하지 않은 정보(출전·유래 등)는 적지 말고 `## 메모`에 `(확인 필요)`로 남길 것

---

## 3. 아직 형식을 정하지 않은 폴더

`drama/`, `translation/`, `hsk/`는 콘텐츠가 어느 정도 쌓인 뒤에 형식을 정합니다.
사자성어처럼 먼저 몇 개 써보고 공통점을 찾는 편이 낫습니다.
